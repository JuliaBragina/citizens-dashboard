# Картотека граждан

Frontend-приложение для просмотра и редактирования сведений о гражданах, выполненное в рамках тестового задания. Включает обзор с графиками, картотеку с поиском и фильтрами и отдельную карточку гражданина.

## Технологии

- React и JavaScript.
- React Router — страницы, параметры фильтров, пагинации и разделов карточки в URL.
- Vite — запуск и сборка.
- CSS с БЭМ-наименованием классов и общими переменными цветов.
- ESLint — проверка кода.

Графики выполнены на React и CSS без отдельной библиотеки диаграмм.

## Возможности

### Обзор

- Общее количество граждан, число записей на учёте и в архиве, количество регионов.
- Кольцевая диаграмма статусов.
- Столбчатые графики распределения по регионам и возрастным группам.
- Переход к картотеке с выбранным статусом.
- Пересчёт показателей после сохранения изменений в карточке.

### Картотека

- Таблица с ФИО, датой рождения, регионом и статусом.
- Поиск по ФИО без учёта регистра и различия между «е» и «ё».
- Совместная фильтрация по региону и статусу, сброс фильтров.
- Количество найденных записей и диапазон отображаемых строк.
- Клиентская пагинация по 10 записей. При изменении фильтров открывается первая страница.
- Открытие карточки по нажатию на строку.
- Сообщение при отсутствии результатов.

Поиск, фильтры и номер страницы сохраняются в URL.

### Карточка гражданина

- Основные сведения и электронная почта.
- Разделы «Семья», «Образование» и «Работа» с таблицами связанных записей.
- Хлебные крошки и переключение разделов через URL.
- Режим редактирования текстовых полей, дат, чисел и выпадающих списков.
- Сохранение и отмена изменений. Черновик сохраняется при переключении разделов.
- Проверка обязательных полей, email, дат и последовательности периодов обучения и работы.
- Открытие раздела с ошибкой и перевод фокуса к проблемному полю.
- Предупреждение при попытке уйти с несохранёнными изменениями.
- Сообщение, если гражданин с указанным ID не найден.

Таблица используется повторно для картотеки и связанных записей. У новых демонстрационных граждан связанные разделы могут быть пустыми. Создание и удаление граждан и связанных записей не реализованы.

## Запуск

Требуется Node.js 20.19+ в ветке 20 либо 22.12+ и npm (согласно требованиям Vite).

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале.

## Проверки и сборка

```bash
npm run lint
npm run build
```

Просмотр собранного приложения:

```bash
npm run preview
```

Результат сборки находится в `dist`.

## Структура

```text
src/
├── components/     # Таблица, поля, графики, пагинация и навигация
├── data/           # Вымышленные данные граждан
├── pages/
│   ├── Dashboard/
│   ├── Citizens/
│   └── CitizenDetails/
├── utils/          # Расчёт показателей, проверка форм и пагинация
├── App.jsx         # Общее состояние граждан и маршруты
├── main.jsx        # Подключение React и роутера
└── index.css       # Базовые стили и цвета
```

JSX и CSS каждой страницы находятся в одной папке. Описание разделов карточки и колонок связанных таблиц хранится в `src/components/CitizenSections/sections.js`.
